## 一、這是什麼

一套 Windows 原生中文輸入法，把三件現成的好東西湊在一起：

- **注音的輸入節奏**——聲調是語意的一部分，該打就打，不靠猜。
- **微軟雙拼的鍵位**——一個音節固定兩鍵，不是一個一個注音符號按。
- **微軟注音的選字**——需要時才按 `8` 開候選視窗，平常畫面清清爽爽。

### 和微軟雙拼是什麼關係

**鍵位完全相同。** 用的就是微軟雙拼那一套對應，包括最容易記錯的四個：

| 拼音 | 鍵 |
|---|---|
| zh | `v` |
| ch | `i` |
| sh | `u` |
| ing | `;` |

從微軟雙拼或小狼毫的 `mspy` 方案轉過來，**手指的肌肉記憶不用重練**。差別在輸入節奏
（聲調嚴格、模態選字）與一整套省鍵設計，也就是本文第四節的內容。

### 一句話說完

> 每個音節最多三鍵（聲母＋韻母＋聲調），**常用字兩鍵**，很多高頻字甚至只要一鍵加空白。

## 二、五分鐘上手

打「你好」：

```
n  i  3      h  k  3      Enter
ㄋ ㄧ ˇ      ㄏ ㄠ ˇ
```

畫面經過的三個階段，整套輸入法都是這三段的變化：

| 階段 | 畫面 | 怎麼進到下一段 |
|---|---|---|
| **打注音** | `ㄋㄧ`（虛線底線） | 按聲調鍵、空白鍵，或直接打下一個音節 |
| **定案成字** | `你`（虛線底線還在） | 按 Enter |
| **上屏** | `你`（底線消失） | 完成，字送進應用程式 |

**虛線底線＝還沒送出去**，只要底線還在，整段都能回頭修改。

### 第一次使用要知道的三件事

1. **新開的程式一律是英文模式。** 單獨輕按一下 `Shift` 切成中文。
2. **空白鍵是「定案」不是「上屏」。** 有待定的注音就先定案，沒有的話就是一個普通的
   半形空白。要送出去請按 `Enter`。
3. **中文模式下數字排打不出數字。** 那排鍵被借去當聲調鍵和控制鍵了；要打數字先按
   `Shift` 切英文（會自動幫你補半形空白），或直接用數字鍵盤。

### 3.3 ㄐㄑㄒ 專屬的 ㄩ 系

**最容易漏掉的一組。** 這些讀音只出現在 ㄐㄑㄒ 後面：

| 鍵 | 注音 | 例 |
|---|---|---|
| `u` 或 `y` | ㄩ | 居 `ju` |
| `t` 或 `v` | ㄩㄝ | 決 `jt` |
| `r` | ㄩㄢ | 捐 `jr`、全 `qr` |
| `p` | ㄩㄣ | 軍 `jp` |
| `s` | ㄩㄥ | 兄 `xs` |

其他聲母要打 ㄩ 系（女、綠、略等），韻母鍵一樣是 `y`／`t`：女 `ny`、略 `lt`。

### 3.4 零聲母

自己就能成字的音（ㄢ ㄣ ㄤ ㄥ ㄦ ㄞ ㄟ ㄠ ㄡ ㄚ ㄜ ㄛ）有兩種寫法：

- **通用**：`o` ＋ 韻母鍵——安 `oj`、歐 `ob`、昂 `oh`、餓 `oe`。
- **疊寫**（限開頭是 ㄚ／ㄜ 的）：把第一個字母打兩次——安 `aj`、愛 `al`、恩 `ef`、二 `er`。

兩種都有效，挑順手的用。

### 3.5 拼不出來的鍵組會被吃掉

`DecodeKeyPair` 只做結構過濾，**真正成不成立由詞庫決定**。國語裡沒有的音節（ㄎㄟ `kz`、
ㄉㄣ `df`、ㄖㄚ `ra`…）按下第二鍵時**直接被吃掉，畫面不動**，不會產生假注音。
所以第二鍵打錯時通常當場就看得出來。

## 四、把鍵數壓到最低

這一節是整套輸入法的設計重點：**同一個字，用最少的鍵打出來**。

### 4.1 不打聲調就有字

聲調規則是**嚴格**的，但預設值挑得很划算：

| 你打的 | 出現的字 |
|---|---|
| **不打數字** | **一聲＋輕聲**（涵蓋最常用的兩類） |
| `1` | 嚴格只要一聲 |
| `2` `3` `4` | 精確的二／三／四聲 |
| `5` | 只要輕聲 |

因為「不打數字」已經同時涵蓋一聲和輕聲，**實務上幾乎不需要打 `1` 和 `5`**——
明打它們只在你要**排除另一個**的時候才有意義（`ge1` 排除輕聲的「個」而要「歌」）。

> 一聲和輕聲的字直接省下一鍵，而這兩類正好是中文裡最高頻的一群。

三聲的「我」則一定要打 `wo3`——`wo` 只會給你「窩」。聲調是語意的一部分，不會幫你猜。

### 4.2 單鍵音節：26 個字母鍵每一個都是音節

**省略韻母鍵**，直接用聲調鍵或空白鍵收尾。分兩類：

**第一類——注音本身就是一個音節**

| 鍵 | 音節 | 例 | 鍵 | 音節 | 例 |
|---|---|---|---|---|---|
| `z` | ㄗ | 自 `z4` | `y` | ㄧ | 一 `y`＋空白 |
| `c` | ㄘ | 此 `c3` | `w` | ㄨ | 五 `w3` |
| `s` | ㄙ | 四 `s4` | `a` | ㄚ | 啊 `a`＋空白 |
| `r` | ㄖ | 日 `r4` | `e` | ㄜ | 惡 `e4` |
| `v` | ㄓ | 之 `v`＋空白 | `o` | ㄛ | 喔 `o`＋空白 |
| `i` | ㄔ | 吃 `i`＋空白 | | | |
| `u` | ㄕ | 是 `u4` | | | |

**第二類——注音的呼名**。你唸「ㄅ」的時候其實唸的是「ㄅㄛ」，那個韻母就是預設值：

| 鍵 | 呼名 | 例 | 鍵 | 呼名 | 例 |
|---|---|---|---|---|---|
| `b` `p` `m` `f` | ㄅㄛ ㄆㄛ ㄇㄛ ㄈㄛ | 播 `b`＋空白、頗 `p3` | `j` `q` `x` | ㄐㄧ ㄑㄧ ㄒㄧ | 機 `j`＋空白、七 `q`＋空白 |
| `d` `t` `n` `l` | ㄉㄜ ㄊㄜ ㄋㄜ ㄌㄜ | **的 `d`＋空白**、**了 `l`＋空白** | `g` `k` `h` | ㄍㄜ ㄎㄜ ㄏㄜ | 個 `g`＋空白、賀 `h4` |

> ㄅㄆㄇㄈ 帶 **ㄛ** 不是 ㄜ（國語根本沒有「ㄅㄜ」這個音節），ㄉㄊㄋㄌㄍㄎㄏ 帶 **ㄜ**，
> ㄐㄑㄒ 帶 **ㄧ**。鍵盤上橘色聲母下方的小字就是它。

**唯一要記的規則：單鍵音節後面一定要用空白鍵或聲調鍵收尾。**
不然下一鍵會被當成它的韻母：

- 知識 = `v` ＋空白＋ `u4`　✔
- 知識 = `vu4`　✘（`v`+`u` 是 ㄓㄨ，住／主）

實作上「省略韻母鍵」等於「幫你按下那個預設韻母鍵」，所以 `d` 和 `de` 是**同一個讀音
ㄉㄜ**，不可能有歧義。這些鍵**仍然可以接韻母鍵**（`u`+`l` = ㄕㄞ、`d`+`l` = ㄉㄞ），
只有空白鍵和聲調鍵會把它當成一個完整音節收掉。

#### 為什麼 `y` 是 ㄧ 不是 ㄩ

詞格的一個節點只能對應一個讀音，兩者無法共用同一鍵。以詞庫的單字使用量計，ㄧ 系比
ㄩ 系常用（單音節約 1.6 倍、整個系列約 2.3 倍），所以 `y` 給了 ㄧ，**ㄩ 仍要打
`yu` 或 `yy`**。ㄦ 同理，仍是 `er`。

這是目前唯一一個「排得進前幾名卻沒有單鍵」的音；剩下能用的第一鍵只有 `;`，代價是
失去全形「；」，衡量後決定先不動。

### 4.3 聲調鍵左右手鏡像

以 `5`／`6` 之間為軸，右手有一組**完全等價**的聲調鍵：

| 聲調 | 左手 | 右手 |
|---|---|---|
| 一聲 | `1` | `0` |
| 二聲 | `2` | `9` |
| 三聲 | `3` | `8` |
| 四聲 | `4` | `7` |
| 輕聲 | `5` | （沒有——`6` 是 `Backspace`） |

用處是**讓聲調鍵落在剛打完音節的另一隻手**。看的是音節的**最後一個字母鍵**在哪一邊：

- 「馬」ㄇㄚˇ ＝ `m`＋`a`，最後一鍵 `a` 在**左手** → 補調用**右手**的 `8`。
- 「上」ㄕㄤˋ ＝ `u`＋`h`，兩鍵都在**右手** → 補調用**左手**的 `4`。

兩手輪流，不會卡在同一隻手上連按。左右手的分界就是一般打字的分界——
左手 `q w e r t` / `a s d f g` / `z x c v b` / `1`–`5`，其餘歸右手。

### 4.4 整句轉換：讓引擎猜，錯了再改

每定案一個音節就重跑一次**整句**轉換，前面的字會依上下文自動修正：

```
v ＋空白      →  之        （單看一個音節，「之」最常用）
u 4           →  知識      （看到後面，「之」自動改成「知」）
```

所以打字時不必停下來確認每一個字，一路打完再看整句。

### 4.5 選字記憶：改一次就記住

手動選過的字會被記住，記的內容是「**在某個字後面，這個讀音要打成哪個字**」。

- **改一次就生效**，不用重複好幾次去「養」它。
- **沒有時間衰減**，也不會因為久沒用就忘記。
- 只有**相同上下文**才套用，換個句子不受影響。
- 想改回去也只要選一次，一樣便宜。
- 自動套用時**只動那一個位置**，句子其他地方不會被連帶改掉；
  而且**你當下手動選的字永遠優先**。

記錄存在 `%APPDATA%\MspyIME\user-choices.txt`。

### 4.6 省鍵對照表

| 字／詞 | 鍵 | 鍵數 | 省在哪 |
|---|---|---|---|
| 的 | `d` ＋空白 | 2 | 單鍵音節＋輕聲免打 |
| 了 | `l` ＋空白 | 2 | 同上 |
| 一 | `y` ＋空白 | 2 | 同上 |
| 是 | `u4` | 2 | 單鍵音節 |
| 自 | `z4` | 2 | 單鍵音節 |
| 中 | `vs` ＋空白 | 3 | 一聲免打數字 |
| 文字 | `wf2` `z4` | 5 | 「字」只用兩鍵 |
| 我的 | `wo3` `d` ＋空白 | 5 | 「的」只用兩鍵 |
| 明天 | `m;2` `tm` | 5 | 「天」一聲免打數字 |
| 安全 | `aj` `qr2` | 5 | 零聲母疊寫＋一聲免打 |

## 五、數字鍵的兩種身分

中文模式下數字排**永遠不會輸出數字**。它有兩種身分，靠畫面一眼分辨：

> **畫面上還是注音** → 數字是聲調鍵（`6` 除外）
> **畫面上已經是字** → 數字是控制鍵

| 按鍵 | 畫面是注音（未定案） | 畫面是字（已定案） |
|---|---|---|
| `1`–`4` | 一～四聲 | 吃掉，無作用 |
| `5` | 輕聲 | **往右刪**（Delete） |
| `6` | **往左刪**（整個音節） | **往左刪**（Backspace） |
| `7` | 四聲 | 吃掉／**上一頁**（選單開著時） |
| `8` | 三聲 | **開候選選單**（選單開著時＝下一頁） |
| `9` | 二聲 | **游標左移** |
| `0` | 一聲 | **游標右移** |

`6` 是**唯一一個兩邊都一樣**的數字：它永遠是 `Backspace`。代價是輕聲少了一個鍵——
輕聲只剩左手的 `5`（而「不打數字」本來就涵蓋輕聲，實務上幾乎不用打）。

聲調鍵一按就成字，所以打完聲調馬上就能按 `8`：`ni3hk3` 後按 `8` 是開選單；
但 `ni3hk` 後按 `8` 是把 ㄏㄠ 變成三聲的「好」。

**選單開著時**還有第三種身分：`1`–`6` 選字、`7` 上一頁、`8` 下一頁，
**其他任何鍵都是「關窗並執行那個鍵原本的功能」**。

## 六、定案與上屏

兩個不同的動作，分清楚了整套操作就順了。

**定案**＝注音變成字（或變成固定的注音符號），但**還在組字串裡**。觸發方式有四種：

1. 聲調鍵
2. 空白鍵
3. 標點符號
4. 下一個音節的第一鍵

**上屏**＝整段送進應用程式，底線消失。**只有三種**觸發方式：

1. `Enter`
2. 點到別的地方（失焦）
3. 組字途中按數字鍵盤（會先整段上屏，再打出那個數字）

**沒有任何自動上屏的界線**——句子想寫多長就多長，中間全都還能改。Shift 切換中英
**不會**上屏，標點**不會**上屏，空白鍵也**不會**。

> **空白鍵沒東西可定案的時候，就是一個普通的半形空白**（2026-08-16 起）。它和標點
> 一樣留在組字串裡：游標走得過去、`Backspace` 刪得掉、和整段一起上屏。以前這個
> 情況下的空白鍵會把整段送出去，現在那件事只有 `Enter` 做。

> **`Enter` 送出的就是畫面上的東西**（2026-08-17 起）。還顯示成注音的部分會
> **原樣送出去**：`n` 送出 ㄋ、`nc` 送出 ㄋㄧㄠ、`k` 送出 ㄎ。以前這些會被丟掉
> 或被偷偷換成字（`k` 會變成「科」），現在不會了——要字就先按空白鍵或聲調鍵。

`Esc` 一次清掉整段組字串。`Backspace` 把還在打的那個音節整個刪掉，成字後逐字刪。

## 七、選字

只有 `8` 會開選單，開在**游標右邊那個字**（淡藍反白的那個）上。

| 按鍵 | 作用 |
|---|---|
| `9` / `0` | 游標左移／右移（到兩端會環繞） |
| `-` / `=` | 跳到組字串的頭／尾 |
| `8` | 開選單；選單開著時＝下一頁 |
| `7` | 上一頁（翻到底不環繞） |
| `1`–`6` | 選第 n 個（每頁最多 6 個） |
| 其他任何鍵 | 關窗，並執行那個鍵原本的功能 |

三個讓選字變快的設計：

- **選完游標自動跳到該詞段之後**，所以可以**連按 `8`** 一路往右改完整句，不用碰游標鍵。
  選到兩個字的詞就跳兩格。
- **選了也不會變的候選一律隱藏**。反白在「懂」而目前是「聽不懂」時，聽不懂／不懂／懂
  都不會列出來；過濾後沒有候選就不開窗。
- **改字只動你選的那幾個字**。整句重新斷詞時，選定範圍以外被改掉的位置會釘回原狀，
  不會出現「改了後面、前面卻跟著變」。

選字視窗開在反白字的正下方，放不下時自動翻到上方，並且會跟著螢幕的 DPI 縮放。

## 八、中英切換與標點

### 8.1 Shift 輕按

**單獨輕按一下 `Shift`**（按下到放開之間沒有按別的鍵）切換中英。`Shift`＋字母照常輸出
大寫，不會誤觸。

**切換不會上屏。** 組字串整段留著，底線還在，英文**直接長在同一個組字串裡**——
中英夾雜的句子可以一口氣打完再檢查，最後才 `Enter`。英文模式下的空白鍵是普通空白，
所以片語、整句英文都打得出來。

**自動補半形空白**（只在組字串內部，依游標左邊的字元判斷）：

| 切換方向 | 左邊是 | 動作 |
|---|---|---|
| 切英文 | 中文字或注音符號 | 補一個半形空白 |
| 切中文 | 英文字母或數字 | 補一個半形空白 |
| 兩者 | 標點、已有空白、空字串 | 不補 |

**沒有組字串時按 Shift 就只是單純切模式**，按鍵全數放行，也不會補空白——
已經上屏的字後面要不要空白由你決定。

**中／英模式每個應用程式各自記憶**，新開的程式一律從**英文**開始（與微軟注音一致）。

### 8.2 標點

標點會**順手定案**前面待定的音節，而且**自己也留在組字串裡**，不上屏。
游標走得過標點，`8` 照樣能對前後的字開選單。閒置時打標點＝直接開一段新的組字串。

| 鍵 | 符號 | 鍵 | 符號 | 鍵 | 符號 |
|---|---|---|---|---|---|
| `,` | ， | `[` `]` | 「」 | `^` | …… |
| `.` | 。 | `{` `}` | 『』 | `_` | —— |
| `?` | ？ | `(` `)` | （） | `~` | ～ |
| `!` | ！ | `<` `>` | 《》 | `"` `'` | 開閉交替 |
| `:` | ： | `\` `/` | 、 | `;` | ；（組字中仍是 ㄧㄥ 韻母鍵） |
| `-` | - | `=` | = | `+` | + |

> 最後一列是**半形**的 `-` `=` `+`，與小狼毫的微軟雙拼一致：中英混排時用得夠多，
> 不值得為一個連接號切一趟英文。其餘符號一律全形。
>
> （數字仍然要切英文或用 NumPad，所以整條算式還是打不出來——見第十一節。）

> 小提醒：標點是用「一聲／輕聲」的預設去定案前面的音節的。`ni3hk` 後直接打 `,`
> 會得到「你**蒿**，」而不是「你好，」——習慣上**先給聲調再打標點**。

## 九、不離開主鍵區

數字排被借來做編輯，手不用移到方向鍵區。它有**兩種身分**，分界是「畫面上還有沒有組字串」——
看得出來，不用記。

**組字中**（畫面上有虛線底線的那一段）：

| 按鍵 | 作用 |
|---|---|
| `9` / `0` | 游標左移／右移 |
| `5` / `6` | 往右刪／往左刪（＝Delete／Backspace） |
| `8` | 開候選選單（選單開著時 `7`/`8` 翻頁、`1`–`6` 選字） |
| 其他數字 | 聲調鍵，或吃掉無作用 |

> `5` 只在**已經定案成字**之後才是 Delete；畫面上還是注音的時候它是輕聲。
> **`6` 沒有這個限制**：它在哪個狀態都是 `Backspace`。還在打的音節按一次就整個消失
> （`bc` 顯示 ㄅㄧㄠ，按一次全沒），成字之後才是一個字一個字刪。

**閒置**（字已經上屏，畫面上沒有組字串）：整排數字變成編輯鍵。

| `1` | `2` | `3` | `4` | `5` | `6` | `7` | `8` | `9` | `0` |
|---|---|---|---|---|---|---|---|---|---|
| 行首 | 選到行首 | 選到行尾 | 行尾 | Delete | Backspace | ↑ | ↓ | ← | → |

- `1`–`4` 由中間往外讀：**左邊兩個往左、右邊兩個往右**，各自靠內的那個帶選取。
- 這排編輯鍵**中文和英文模式完全一樣**，習慣不用隨模式切換。
- **只吃沒按 `Shift` 的數字**：`Shift`+`1`＝！、`Shift`+`9`＝（ 照常打得出來。
- 按著 `Ctrl` 或 `Alt` 一律不攔，`Ctrl`+`1` 還是應用程式的快捷鍵。
- `Tab`、`-`、`=` **完全沒有被攔截**：切換欄位、縮排、自動完成都照常。

**代價**：中文模式下數字排打不出數字。三條路可以打：

1. **鍵盤右邊的數字鍵**（NumPad）——完全不受影響，閒置時直接輸出數字，組字中則先整段上屏再輸出。
   注意 NumLock 要開著。
2. **按 `Shift` 切英文**。英文模式下只要已經在打一串字，數字鍵就是數字，`user123` 一路打得完。
3. 筆電若沒有數字鍵盤：`Fn` 由鍵盤韌體處理、作業系統看不到，所以不能拿來當修飾鍵；
   有內嵌數字鍵盤的機型（`Fn`+`U` `I` `O` `J` `K` `L` `M`…）送出的是真正的 NumPad 鍵，第 1 條適用。

## 十、打注音符號本身

兩條路，都不用記特殊鍵。

**一、直接按 `Enter`。** 畫面上還是注音的部分會原樣送出去：`n` → ㄋ、`nc` → ㄋㄧㄠ、
`k` → ㄎ。要字才需要先按空白鍵或聲調鍵。

**二、按空白鍵——但只在這個音節沒有字的時候。** 一個音節既沒有一聲也沒有輕聲的字時，
空白鍵沒有字可以定案，就把注音本身定案成符號留在組字串裡。例如 `nc`（ㄋㄧㄠ，詞庫只有
ㄋㄧㄠˇ／ㄋㄧㄠˋ）和 `f`（ㄈㄛ 只有二聲的「佛」，所以 `f`＋空白得到 ㄈ，要「佛」請打 `f2`）。
反過來說，有字的音節按空白鍵就會變成字：`k`＋空白是「科」不是 ㄎ。

定案後的注音符號可以和中文混排、用游標編輯、`Backspace` 逐符號刪、一起上屏。

> **單獨的韻母（ㄠ、ㄧㄝ）打不出來。** 以前有個反引號 `` ` `` 可以「挖空聲母」來打，
> 2026-08-17 整組拿掉了——那顆鍵現在就是普通的半形 `` ` ``。

## 十一、疑難排解

**打不出數字。**
中文模式下數字排是聲調鍵、控制鍵和編輯鍵。用鍵盤右邊的數字鍵，
或按 `Shift` 切英文再打（詳見第九節的三條路）。

**打不出 `@` `#` `$` `%` `&` `*` `|`。**
這些鍵在中文模式沒有對應的符號，所以按了沒反應——與「數字排打不出數字」
是同一個取捨。按 `Shift` 切英文就打得出來。
`-` `=` `+` **不在此列**（2026-08-16 起直接打出半形字元），
`_`（`Shift`+`-`）也不是，它是全形破折號「——」。

**剛開的程式怎麼是英文？**
設計如此，每個程式各自記憶模式，新程式一律從英文開始。按一下 `Shift` 切中文，
之後回到這個程式就會記得。

**打了字卻沒送出去。**
沒有自動上屏。按 `Enter`——自 2026-08-16 起那是唯一的上屏鍵（點到別的地方也會送出）。
空白鍵在沒有待定注音時只會打出一個半形空白。

**打錯聲調了。**
`Backspace` 刪掉整個音節重打。聲調鍵一按就成字，沒有「只退聲調」這一步。

**選了字，下次還是出錯的。**
記憶是綁上下文的——同一個讀音在不同的前文會分開記。在**同樣的**上下文再選一次就會生效。

**輸入法出現在清單裡但完全沒反應。**
缺少 Microsoft Visual C++ 2015–2022 可轉散發套件。裝好後重開應用程式。

**我裝的是哪一版？**
把滑鼠移到工作列右下角的「特」圖示上，提示裡的名稱後面就是版本號
（例如「阿特雙拼輸入法 v0.8.1」）。「設定 → 時間與語言 → 語言與地區」
的鍵盤清單顯示同一行字。版本號是**安裝時**寫進系統的，所以升級後看到的
就是新版；如果沒變，代表安裝程式沒跑完。

**改了設定或重裝後沒變化。**
已經載入輸入法的應用程式要**重開**才會吃到新的 DLL。
