# Words the filler generator must never pick, one per line.
#
# scripts\build-drills.ps1 seeds the ban list with these before the greedy
# cover runs, so the syllables they would have covered get some other word.
# This is for judgement calls -- unreadable characters are handled by
# MIN_CHAR_SCORE in make-filler-lessons.py instead.

什麼    # 詞庫裡 ㄕㄣˊ／ㄕㄜˊ 四種鍵同分，貪婪法會挑到 ㄕㄜˊ-ㄇㄛ˙；
        # 但〈單鍵音節〉那一課已經釘成 ㄕㄣˊ-ㄇㄛ˙，
        # 同一個詞在兩課教兩種讀音只會讓人困惑

那樣    # 詞庫同時收 ㄋㄚˋ-ㄧㄤˋ（正確）與變體 ㄋㄚˇ-ㄧㄤˋ，貪婪法為了覆蓋 ㄋㄚˇ
        # 會挑到三聲那一個。台灣用法裡 ㄋㄚˇ 是「哪」、「那樣」的那讀四聲，
        # 所以兩個讀音都由〈九、收尾〉手寫課文釘死（哪裡／那樣），補完不再碰它
