// Typing-drill lessons for the tutorial site. Format: cli/drill_gen.cpp.
//
//   #id / #title / #intro start a lesson; every other line is one sentence.
//   Words are separated by spaces. A line must END with 。！？ -- that is
//   where the drill checks the walk and presses Enter TWICE: once to send
//   the buffer, once to break the line. Commas inside the line are what
//   join clauses into one sentence, so use them.
//   The reading comes from the dictionary; add one after a slash when the
//   word has more than one (的/ㄉㄜ˙).
//
// Tones 1 and 5 are never typed (no digit already means "tone 1 or
// neutral"), so lessons never have to think about them.
//
// The graded lessons below are hand-written. The filler lessons that follow
// them are produced by scripts/make-filler-lessons.py, which picks real
// dictionary words to cover whatever syllables the graded ones miss.
