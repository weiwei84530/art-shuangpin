阿特雙拼輸入法 — macOS
======================

注音式的輸入節奏，微軟雙拼的鍵位。


安裝
----

1. 把這個資料夾裡的 install.command **按右鍵 → 打開**。

   一定要用右鍵。直接雙擊會被系統擋下來，說「無法打開，因為
   來自身分不明的開發者」——那是所有從網路下載、又沒有付費
   開發者憑證的程式都會遇到的一次性確認。按右鍵打開時會多一個
   「打開」按鈕，按下去就好。

2. 跳出的視窗裡按 Enter 或輸入密碼（只有清除舊授權那一步需要）。

3. 照最後印出來的說明，到系統設定把輸入法加進輸入來源：

   系統設定 → 鍵盤 → 文字輸入 → 輸入來源 → 編輯… → ＋
   在「中文（繁體）」底下選「阿特輸入法」。


輔助使用權限
------------

按 9 一次，跳出詢問時按「同意」。

這是給「閒置時的游標移動鍵」用的：9 / 0 是左右、- / = 是行首行尾。
輸入法本身不授權也能正常打字，只是那四顆鍵不會動。

**每次更新版本都要重做一次。** 這不是 bug：macOS 把這個授權綁在
程式的簽章上，而每一版的簽章都不一樣，所以舊的那一列即使還打著
勾也已經失效了。安裝程式每次都會先幫你清掉，所以按 9 一定會再問
一次。


怎麼打
------

每個音節兩個鍵：聲母 + 韻母。和微軟雙拼的鍵位相同
（zh→v、ch→i、sh→u、ing→分號），肌肉記憶不用重練。

  你好    ni3hk3        聲調用數字，1-5 或右手的 0-6 都可以
  的      d 空白        常用字只要一個鍵
  中      vs 空白

不打聲調也會出字，整句打完再看。要改字就按 8 開選單，
1-6 選字、7/8 翻頁、9/0 移動游標。

完整的說明在專案網站：
  https://weiwei84530.github.io/art-shuangpin/

手冊（含全部鍵位表與省鍵技巧）：
  https://github.com/weiwei84530/art-shuangpin/blob/main/docs/guide.md


移除
----

執行同一個資料夾裡的 uninstall.command（一樣是右鍵 → 打開）。
它會問要不要一起刪掉選字記憶。

------

先看網站的疑難排解，還是不行就開一個 issue：
