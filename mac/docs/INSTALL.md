# 阿特雙拼輸入法（macOS 版）安裝說明

注音式輸入節奏 ＋ 微軟雙拼鍵位 ＋ 微軟注音式的模態選字。
與 Windows 版共用同一套 C++ 輸入核心，這裡只是 macOS 的原生外殼。

---

## 兩種安裝方式

| | 用釋出的 zip | 從原始碼建置 |
|---|---|---|
| 需要什麼 | macOS 11 以上，**其他都不用** | 再加上 Command Line Tools（含 git 與 python3） |
| 要多久 | 十幾秒 | 第一次五到十分鐘（詞庫要建） |
| 適合誰 | 幾乎所有人 | 想跑還沒發佈的改動 |

**大部分人用第一種。** 下面第一節就是。

---

## 一、用釋出的 zip 安裝

1. 到 [Releases](https://github.com/weiwei84530/art-shuangpin/releases) 下載
   `art-shuangpin-mac-vX.Y.Z.zip`。

2. 解壓縮，把裡面的 `install.command` **按右鍵 →「打開」**，再按一次「打開」。

   **一定要用右鍵。** 直接雙擊會被系統擋下來，說「無法打開，因為來自身分不明的開發者」——
   所有從網路下載、又沒有付費開發者憑證的程式都會遇到這個一次性確認。

3. 過程中可能會問管理者密碼（只有清除舊的輔助使用授權那一步需要，可以按 Ctrl-C 跳過）。

4. 跳到第三節，把輸入法加進系統。

要更新就下載新版的 zip 再做一次同樣的事，輸入來源不用重加。

---

## 二、從原始碼建置

只有在你要跑「還沒發佈」的改動時才需要這條路。先裝 Command Line Tools（不需要完整的 Xcode）：

```sh
xcode-select --install
```

然後把 repo 裡的 `mac/bootstrap.command` 複製到 Mac 上任何地方雙擊。它會自己 `git clone`
這個專案（公開的，不用登入）、建詞庫、建置、安裝，一路到底。預設裝在 `~/art-shuangpin`。

之後要更新，就雙擊 `~/art-shuangpin/mac/bootstrap.command`：它會 `git pull` 再重新建置安裝。

`mac/` 資料夾裡有四個可以直接雙擊的檔案，不需要開終端機：

| 檔案 | 做什麼 |
|---|---|
| `bootstrap.command` | 更新程式碼、必要時建詞庫，然後做下面 `install.command` 那件事。 |
| `check-engine.command` | 只編譯輸入核心與詞庫引擎、跑一次組字測試。不安裝、不碰系統。 |
| `install.command` | 清掉舊的建置產物 → 重新建置 → 安裝到 `~/Library/Input Methods/` → 註冊輸入來源。 |
| `uninstall.command` | 移除。會先問要不要一併刪掉學過的詞。 |

雙擊會自己開「終端機」跑完，跑完停住等你按 Enter，看得完訊息再關。
第一次建議先跑 `check-engine.command`，看到最後一行是 `FINAL COMMIT: "你好中"`
就表示核心在這台機器上是好的。

`install.command` 還會自動偵測鑰匙圈裡有沒有名為 `ArtShuangpin Dev` 的自簽憑證，
有就拿來簽章——這樣輔助使用權限不會每次重建都失效（見第四節）。沒有也照樣能裝。

### 想自己打指令的話

```sh
cd art-shuangpin/mac
bash ../scripts/build-data.sh    # 只有第一次要跑，產生 ../out/data.txt
make clean && make install       # 等同 install.command
make probe                       # 等同 check-engine.command
build/repl --data ../out/data.txt --keys "ni3hk3vs"
```

產物是 `mac/dist/ArtShuangpin.app`。預設只編譯這台 Mac 的架構；要編通用版本：

```sh
make ARCH="arm64 x86_64"
```

## 三、把輸入法加進系統

安裝完之後到：

> 系統設定 → 鍵盤 → 文字輸入 → 輸入來源 → 編輯… → **＋**

在**中文（繁體）**底下選「阿特輸入法」加入。

如果清單裡找不到，登出再登入一次通常就會出現。

> **選單列上的名稱／圖示還是舊的**（名稱顯示成
> `com.mspy.inputmethod.ArtShuangpin.Chinese`，圖示還是正方形）
>
> 先看**系統設定這一頁**顯示的是什麼。如果這裡已經是「阿特輸入法」＋長方形紅圖示，
> 那就表示安裝完全正確，**只有選單列在拿舊的快取**——系統設定會重新讀檔，
> 畫選單列的是另一支常駐程式，它不會。
>
> 由輕到重試：
>
> 1. 在終端機 `killall ArtShuangpin`
> 2. 在這一頁用「－」把它移除、按 Done，再用「＋」加回來
> 3. **登出再登入一次**——這個一定有效，登入時整份輸入來源清單會重新掃描
>
> 想先確認安裝本身沒問題的話：
>
> ```sh
> ls "$HOME/Library/Input Methods/ArtShuangpin.app/Contents/Resources"
> ```
>
> 看得到 `en.lproj` 就對了。

## 四、輔助使用權限（只影響閒置導航鍵）

沒有組字的時候，`9` `0` `-` `=` 會被輸入法攔下來、代送成游標移動鍵，
Tab 則代送成 Backspace。這件事需要系統授權：

> 系統設定 → 隱私權與安全性 → **輔助使用** → 把 ArtShuangpin 打開

第一次按到這幾個鍵時系統會自己跳出詢問。**不授權也能正常打字**，只是這幾個鍵沒有作用
（中文模式下閒置的 Tab 一樣會被吃掉，所以不授權的話它也不會切換欄位；要切欄位用 Shift+Tab）。

**每次重新安裝之後這個權限本來會失效**，因為本機的臨時簽章每次建置都不一樣，
而系統是認簽章的。麻煩的地方在於**清單裡那一列還在、而且還打著勾**——它對應的是
上一次建置的版本，看起來已經授權，實際上對新版沒有效力。

> **這件事現在 `install.command` 會自己處理。** 用臨時簽章安裝時，它會在裝完之後
> 執行 `tccutil reset Accessibility`，把那一列失效的授權清掉，然後重開輸入法。
> 這樣你按一次 `9` 就一定會跳出授權詢問，按「同意」即可。
>
> 這個指令視 macOS 版本有時需要管理者權限。安裝程式會先用一般身分試，
> 失敗才改用 `sudo` ——那時終端機視窗會直接問你密碼，輸入即可
> （不想做就按 Ctrl-C 跳過，不影響其他功能）。

**不想每次重裝都重新授權一次**：做一個自簽憑證，權限就不會因為重建而失效。
在「鑰匙圈存取」→ 憑證輔助程式 → 建立憑證…，名稱填 `ArtShuangpin Dev`、
識別類型選「自我簽署的根憑證」、憑證類型選「程式碼簽署」。

只要做這一次。之後 `install.command` 會自己找到它並拿來簽章，也**不會再去清授權**
（憑證簽的版本授權本來就活得下來，清掉反而是多此一舉）。
自己打指令的話是 `make install SIGN_ID="ArtShuangpin Dev"`。
詳細步驟見 `docs/NOTES.md` 的〈Ad-hoc signing and Accessibility〉。

## 怎麼打字（速查）

| 動作 | 按鍵 |
|---|---|
| 一個字 | 聲母鍵 + 韻母鍵（例：`ni` `hk` `vs`） |
| 一鍵就成字的音節 | **26 個字母鍵全部都可以**：省掉韻母鍵，直接按聲調鍵或空白鍵就成字。字＝`z4`、是＝`u4`、知＝`v`＋空白、的＝`d`＋空白、機＝`j`＋空白 |
| 聲調 | 緊接著打——左手 `1` `2` `3` `4` `5`，右手 `0` `9` `8` `7` `6`（同一組，鏡像）；不打＝只出一聲與輕聲。**打了聲調就直接成字** |
| 打錯聲調 | **Backspace** 把整個音節刪掉重打（沒有「退調」這一步） |
| 刪除 | Backspace，或 **Tab**（同一件事，手不用離開主鍵區） |
| 定案 | **空白鍵**：把還沒定案的注音變成字 |
| 開候選選單 | 先定案，再按 `8`（對游標右邊那個底線特別粗的字） |
| 選字 | 選單開著時 `1`-`6`（選完游標自動跳到該詞後面，可以連按 `8` 一路往右改） |
| 翻頁 | `7` 上一頁、`8` 下一頁 |
| 游標左右移 | 先定案，再按 `9` / `0`（兩端環繞） |
| 游標跳頭／尾 | 先定案，再按 `-` / `=` |
| 上屏 | Enter（或在沒有東西可定案時再按一次空白鍵） |
| 清空 | Esc（一次全清） |
| 中英切換 | 單獨輕按一下 **Shift**（**不會**把字送出去，英文接著長在同一串裡） |
| 打數字 | 先用 Shift 切到英文（中文模式下數字全部是控制鍵） |

### 「未定案」是什麼

剛打完的那個音節會**先顯示注音**——打 `hk` 看到的是 ㄏㄠ，還不是「好」。
按**聲調鍵**、**空白鍵**、打**標點**、或直接接著打**下一個字**，它才會變成中文字。

這個「未定案」狀態決定了數字鍵是什麼：

| 畫面上 | `0`-`9` | `-` `=` |
|---|---|---|
| 還看得到注音（ㄏㄠ） | 全部都是**聲調鍵** | 沒作用 |
| 已經是中文字了（好） | `8` 開選單、`9` `0` 移游標、其餘沒作用 | 游標跳組字串最前／最後 |

規則只有一句：**只要畫面上還有注音，數字就不是控制鍵。**
聲調鍵本身就會讓它成字，所以打完聲調馬上就能按 `8` 選字；只有「不打聲調」的字要先按一次空白鍵。

### 一鍵就是一個字（26 個字母鍵都可以）

省掉韻母鍵，直接按**聲調鍵**或**空白鍵**，一個字只要兩鍵：

| 鍵 | 注音 | 例 |
|---|---|---|
| `z` `c` `s` `r` | ㄗ ㄘ ㄙ ㄖ | 字＝`z4`、日＝`r4` |
| `v` `i` `u` | ㄓ ㄔ ㄕ | 知＝`v`＋空白、是＝`u4` |
| `y` `w` | ㄧ ㄨ | 一＝`y`＋空白、五＝`w3` |
| `a` `e` `o` | ㄚ ㄜ ㄛ | 啊＝`a`＋空白、餓＝`e4` |
| `b` `p` `m` `f` | ㄅㄛ ㄆㄛ ㄇㄛ ㄈㄛ | 播＝`b`＋空白、頗＝`p3`、麼＝`m5` |
| `d` `t` `n` `l` `g` `k` `h` | ㄉㄜ ㄊㄜ ㄋㄜ ㄌㄜ ㄍㄜ ㄎㄜ ㄏㄜ | 的＝`d`＋空白、了＝`l`＋空白、個＝`g`＋空白 |
| `j` `q` `x` | ㄐㄧ ㄑㄧ ㄒㄧ | 機＝`j`＋空白、七＝`q`＋空白、西＝`x`＋空白 |

前四列是「注音本身就是一個音節」；後三列是**注音的呼名**——ㄅㄆㄇㄈ 唸的時候帶 ㄛ、
ㄉㄊㄋㄌㄍㄎㄏ 帶 ㄜ、ㄐㄑㄒ 帶 ㄧ。所以 `d` 跟 `de` 是同一個讀音，沒有例外要記。

兩個要注意的：

* `f`＋空白**打不出字**（ㄈㄛ 只有二聲），會定案成注音符號 ㄈ；佛＝`f2`。
* `n`＋空白現在是「呢」。要打純注音 ㄋ 請用 `` n` ``。

這些鍵**還是可以接韻母鍵**（`u`＋`l`＝ㄕㄞ），所以「它到底收在哪裡」得由你決定：
**單鍵音節與下一個字之間一定要用空白鍵或聲調鍵隔開**，沒有例外。
知情＝`v`＋空白＋`q;2`、知識＝`v`＋空白＋`u4`。拼不出音節的鍵會被吃掉（`v`＋`q` 維持 ㄓ）。

### 標點不會把字送出去

打標點（`,` `.` `?` `!` …）會先把未定案的注音變成字，然後標點本身也**加進同一串組字**——
整段仍然帶著底線、還沒送進應用程式。標點之後照樣可以移游標、按 `8` 選前面的字。

沒有在組字時打標點，就直接開一段新的組字串。

**沒有任何自動上屏。** 組字串想多長就多長，只有這幾件事會把字送出去：
Enter、沒有東西可定案時按空白鍵、以及把游標點到別的地方（失焦）。

### 中英切換也不會把字送出去

輕按 Shift 切到英文之後打的英文，會**直接接在同一串組字裡**（整段仍然帶著底線），
兩種文字中間需要的半形空白由輸入法自己補上。再按一次 Shift 切回中文可以繼續接中文，
整段等到按 Enter 才一次送出。英文模式下的**空白鍵是真的空白**，這樣才打得出多個英文字。

沒有在組字時輕按 Shift，就只是單純切模式：按鍵全部放行給應用程式，也不會補空白。

### 其他

組字中整段文字會有底線；**游標右邊那個字的底線特別粗**，那就是按 `8` 會選到的字。

**中／英模式每個應用程式各自記憶**：剛開啟的應用程式一律是英文，按 Shift 切成中文；
切去別的應用程式再切回來，會回到你在那邊留下的模式。應用程式關掉再開，回到英文。

沒有組字時 `9` `0` `-` `=` 變成游標左移、右移、行首、行尾，**Tab 變成 Backspace**
（刪掉已經送出去的字）。Shift+Tab 不攔，欄位反向切換照舊可用。

## 移除

雙擊 `uninstall.command`，它會問要不要一併刪掉學過的詞。自己打指令的話：

```sh
bash scripts/uninstall.sh            # 保留學過的使用者詞
bash scripts/uninstall.sh --purge    # 連使用者詞一起刪
```

輸入來源清單裡的項目可能要自己用「－」按鈕移掉。

## 疑難排解

**輸入來源清單裡沒有這個輸入法**
先登出再登入。還是沒有的話，多半是 `Info.plist` 的問題，`docs/NOTES.md` 有記錄要看哪裡。

**選了輸入法但打字沒反應，出來的是英文字母**
先確認是不是**還在英文模式**——每個應用程式剛開啟時都是英文，輕按一下 Shift 切成中文。
點一下選單列的輸入法圖示，選單裡「中文輸入」「英文輸入」哪一項打勾就是現在的模式。

模式已經是中文卻還是出英文字母，那是詞庫沒載入成功，輸入法會自動退化成「完全放行」
以免卡住你打字。同一個選單最上面會寫「⚠️ 詞庫未載入：<路徑>」。

用 zip 裝的話這不該發生（詞庫就在 app 裡面），若真的遇到請回報。
自己建置的話多半是 `../out/data.txt` 沒建成功，重跑一次
`bash ../scripts/build-data.sh` 再 `make install`。

**改了程式重新安裝，行為卻沒變**
輸入法是常駐程式，舊的還在跑。`make install` 會自動先關掉它；手動的話：

```sh
killall ArtShuangpin
```

**想看詳細紀錄**

```sh
defaults write com.mspy.inputmethod.ArtShuangpin debug -bool YES
killall ArtShuangpin
```

之後在「主控台」（Console.app）搜尋 `ArtShuangpin` 就看得到。關掉：

```sh
defaults write com.mspy.inputmethod.ArtShuangpin debug -bool NO
```

**學過的詞存在哪**

```
~/Library/Application Support/ArtShuangpin/user-choices.txt
```

一行一筆，格式是 `值 讀音鍵 上下文 次數 序號`。每一筆記的是
**「接在〈上下文〉後面，這個讀音要打成這個字」**——例如你把「不鏽鋼悲」的「悲」改成
「杯」，記下來的就是「鋼→杯」與「鏽鋼→杯」兩筆。

**改一次就會記住。** 選過的字會直接壓過詞庫的判斷，不必連續改好幾次；改回去一樣只要一次。
沒有時間衰減，久沒用到也不會忘掉——決定強弱的是你**最後一次**怎麼選，不是多久以前選的。

上下文取的是前面一到兩個字，兩種長度都會記，所以同樣的習慣在沒提到「鏽」的句子裡也會生效。

如果你用過 0.3.0 以前的版本，舊的 `user-phrases.txt` 會被改名成 `user-phrases.txt.bak`
留在原地（不會刪掉）。舊格式沒有「上下文」這一欄，沒辦法轉換，所以新的檔案是從空的開始學。

直接把這個檔案刪掉就等於忘掉所有學過的詞。
